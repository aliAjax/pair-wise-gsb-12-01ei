# 车辆调度工作台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Naive UI
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

这是一个功能最小闭环前端项目，数据默认保存在浏览器localStorage中，方便后续扩展接口、权限、图表或地图能力。

## 调度规则

- 每项任务记录计划日期，车辆、司机作为独立资源台账维护。
- 派车/改期/换人时，同一天内同一车辆或司机最多只能有一个未完成任务（待执行或执行中），冲突即拒绝保存并保留原安排。
- 任务完成后自动释放当天资源，可再次派车。
- 每次创建、调整、状态流转都会写入任务的变更记录。
- 列表支持按计划日期和状态筛选；旧版本数据打开后自动迁移，可继续派车。
