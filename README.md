# 车辆调度工作台

- 行业：物流
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

数据保存在浏览器 localStorage 中（键 `dfwlfront-3-dispatch-v2`），方便后续扩展接口、权限、图表或地图能力。

## 功能

- **按日期派车**：每项任务记录计划日期，车辆、司机维护在独立的资源台账中，不再和任务混在一条记录里。
- **资源占用校验**：派车时当天有待执行 / 执行中任务的车辆和司机不可选；保存前再做一次硬校验，防止重复派出。
- **改期 / 换人**：调整已排任务时，若车辆或司机当天已有别的安排，弹窗列出冲突并拒绝保存，原安排保持不变。
- **变更留痕**：新建派车、改期、换车、换人、状态流转、完成、删除均记录在「变更记录」中（最多保留 200 条）。
- **完成释放**：任务完成后当天的车辆与司机自动恢复空闲，可继续派车。
- **按日期 / 状态查看**：任务列表支持日期筛选（含「今天」快捷按钮）和状态筛选。
- **旧数据兼容**：首次打开会自动迁移旧版本（`dfwlfront-3-dispatch`）混合记录：车辆/司机拆分进台账，旧状态“空闲”转为“待执行”，迁移后可继续派车；旧数据不删除。
